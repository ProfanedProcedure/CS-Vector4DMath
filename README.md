# Vector4DMath
- Generated by Claude.ai

Unity用の4次元幾何学ライブラリ。`Vector3` / `Matrix4x4` / `Quaternion` が持つ機能一式を、
そのまま4次元へ拡張することを目指した構成。

`UnityEngine.Vector4` は同次座標(w成分)付きの3Dベクトルであり、本ライブラリの
`Vector4D` とは別物（名前空間 `Vector4DMath` の下で衝突しないようにしてある）。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `Vector4D.cs` | 4次元ベクトル本体。`Vector3` 相当の全機能 + 4D特有の3引数外積 |
| `Matrix4x4D.cs` | 4x4行列。6つの基本回転面(XY,XZ,XW,YZ,YW,ZW)による回転生成 |
| `Rotor4D.cs` | クォータニオン2つで表す一般回転(二重回転・等傾回転) |
| `Projection4D.cs` | 4D→3D投影とテッセラクト頂点/辺の生成(可視化用) |

## 3次元との違いで押さえておくべき点

1. **外積は2本のベクトルからは作れない。**
   n次元で「全部に直交する1本」を作るには n-1 本のベクトルが必要。3次元の
   「2本→1本」はこの一般則のたまたまの特例。4次元では3本のベクトルが要る。
   → `Vector4D.Cross(a, b, c)`

2. **回転は「軸」ではなく「平面」を基準に起きる。**
   3次元の回転軸は、実は「回転しない平面の法線」を表す便宜的な代用品でしかない。
   次元が上がると軸そのものが意味を失い、4次元には独立な2次元回転面が6つある。
   → `Matrix4x4D.RotationXY / XZ / XW / YZ / YW / ZW`

3. **一般の回転は2つの独立した回転面の組み合わせ(二重回転)になる。**
   両方が同じ角度なら「等傾回転」と呼ばれる、空間全体が同じ角度でねじれる
   4次元特有の回転になる。
   → `Rotor4D`（内部ではクォータニオンのサンドイッチ積 `v' = p·v·q⁻¹` を利用）

4. **符号付き角度(SignedAngle)は存在しない。**
   符号付き角度は「回転面」を1つ固定して初めて定義できる概念で、3次元のように
   軸1本を法線として使う手が使えない。意図的に未実装。

## 基本的な使い方

```csharp
using Vector4DMath;

// ベクトル
Vector4D a = new Vector4D(1, 0, 0, 0);
Vector4D b = new Vector4D(0, 1, 0, 0);
Vector4D c = new Vector4D(0, 0, 1, 0);
Vector4D normal = Vector4D.Cross(a, b, c); // (0,0,0,±1) 相当

float dist = Vector4D.Distance(a, b);
Vector4D mid = Vector4D.Lerp(a, b, 0.5f);

// 単一平面での回転
Matrix4x4D rot = Matrix4x4D.RotationXW(45f);
Vector4D rotated = rot * a;

// 二重回転(2平面を独立した角度で)
Matrix4x4D doubleRot = Matrix4x4D.DoubleRotation(0, 1, 30f, 2, 3, 60f); // XY面30°, ZW面60°

// ローターによる等傾回転
Rotor4D rotor = Rotor4D.Isoclinic(Quaternion.AngleAxis(45f, new Vector3(1, 1, 1).normalized));
Vector4D isoRotated = rotor.Rotate(a);

// 可視化: テッセラクトを生成して3Dへ投影
Vector4D[] verts = Projection4D.GenerateTesseractVertices(1f);
var edges = Projection4D.GenerateTesseractEdges();
foreach (var v in verts)
{
    Vector3 screenPos = Projection4D.ProjectPerspective(v, wDistance: 3f);
    // ここで Gizmos.DrawSphere(screenPos, 0.05f) などに渡す
}
```

## 拡張の余地

- 平行移動を含めたアフィン変換をやるなら 5x5 の同次座標行列が必要（未実装）。
- 任意の一般回転から、直交する2つの回転面を自動抽出したいなら固有値分解が必要
  （現状の `DoubleRotation` は既知の2平面を指定する簡易版）。
- 4次元多胞体（正八胞体以外の正多胞体など）の頂点/辺/面データ生成。
